# ADR-0029：安卓阅读导航、连接管理与富媒体

- 状态：Accepted
- 日期：2026-09-06
- 取代范围：ADR-0022～0025 中尚未接入的移动文档链接、图片和 Mermaid 展示；其余共享及离线边界继续生效。

## 背景

手机主要用于阅读。系统返回直接退出、链接不可跳转、图片和图表只有占位，以及无法清理失效电脑地址，阻碍了正常阅读。

## 决策

1. 阅读页中央区域的轻点切换下方菜单，顶部保留可访问的菜单按钮。滑动、长按选字、链接、图表、表格与代码操作不触发菜单；菜单和阅读设置覆盖正文，不挤压滚动区。
2. Android 系统返回先关闭图像查看器、大纲、设置或菜单；随后返回上一篇链接文档、文件列表、父目录、工作区列表和连接页。连接页首次返回提示，2 秒内再次返回才退出；应用进入后台重置退出计时。软键盘仍由 Android 处理。桌面和浏览器的退出行为不受影响。
3. `.md/.markdown` 相对链接、共享根相对链接及标题锚点在当前工作区内跳转；支持中文、空格、百分号编码和引用式链接。线上逐层查目录得到 opaque ID，离线查询完整快照；根外、非 Markdown、外部网址或缺失目标提示并保留当前页。链接返回轨迹只在内存保留最近 8 篇，返回恢复各自数值阅读位置，不持久化正文或轨迹。
4. 保存或发现的电脑可修改地址、删除连接。修改保留连接 ID、离线内容与最近阅读身份；删除仅移除连接地址，离线内容保留独立入口，继续由既有“清除离线”动作管理。删除的发现地址本地有界隐藏，手动重新连接可恢复，不新增设备身份或配对系统。
5. 图片通过既有只读 `assets/resolve` 与二进制接口加载，共享根和单图 16 MiB 上限不变。支持 PNG/JPEG/GIF/WebP/BMP/ICO，并增加 SVG；资源 SVG 始终作为 `<img>`，不进入 innerHTML/object/frame，直接访问 HTTP 资源也采用 sandbox 策略。离开文档释放对象 URL；当前离线快照仍不包含图片，离线明确提示缺失资源。
6. Mermaid 使用随应用打包的渲染器，在图表接近视口后本地生成 SVG，包括流程图、时序图和思维导图；离线也能渲染已保存的源码。源文最多 50,000 字符，8 秒超时或失败局部回退且可查看源码。图片和图表查看器支持双指缩放、单指平移、按钮缩放和适合屏幕，SVG 保持矢量，关闭恢复打开前的位置。
7. 公式继续使用受限 KaTeX，普通代码保持字面文本并支持复制和选择；GFM 表格局部横向滚动，列对齐、只读任务列表、引用式图片及脚注可显示。原始 HTML 保持文本，不执行脚本。不新增手机正文编辑、文件写入、外部网页浏览或后台资源下载。

## 验证

覆盖线上/离线文档链接、缺失目标、位置返回、父目录返回、连接地址编辑和删除、菜单与选择/滑动互不干扰、富媒体成功/失败、资源释放、矢量缩放及关闭位置。原生 Android 构建与实际设备交互应分开记录，不能以浏览器或单测冒充真机系统返回验收。
