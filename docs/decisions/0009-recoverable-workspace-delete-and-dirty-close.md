# ADR-0009：可恢复的工作区删除与可靠 dirty 关闭

- 状态：Accepted
- 日期：2026-09-01
- 修订：ADR-0008 中“不提供删除”的范围，以及既有 dirty 关闭提示的呈现方式
- 保持不变：ADR-0005 的精简本地边界与三项护栏；ADR-0006 的真可视/显式源码；ADR-0007 的多工作区集合和单一右侧栏；ADR-0008 的保存策略与可视表格

## 背景

继续在真实工作区使用后出现两类高频问题。第一，文件树缺少复制路径、关闭工作区和删除入口，多根同时展开时也难以收拢。第二，文档在同一 Tab 内从 `00` 导航到 `01` 后，`00` 的 dirty session 只存在于 back history：当前 Tab 不显示未保存标记，WebKit 中的同步确认框又可能没有可靠呈现，最终表现为 Tab 和整个应用都无法关闭。

用户明确要求补齐这些动作。产品仍是普通本地编辑器，因此删除必须保持可恢复和受工作区边界约束，不扩展为通用文件管理器。

## 决策

### 1. dirty 状态按整个 Tab 历史聚合

- Tab 的未保存标记检查 `current/back/forward` 引用的全部 session，而不只检查当前页面。
- 关闭 Tab、窗口或应用时使用应用内非阻塞确认对话框，不再依赖同步 `window.confirm`。
- 取消保持原 Tab、窗口与进程；确认才丢弃被关闭范围内的未保存内存正文并继续关闭。
- 原生红色关闭、原生菜单关闭与退出继续进入同一前端检查；确认后只执行一次窗口销毁，主窗口销毁后进程退出。

### 2. 工作区根可折叠并可从窗口集合关闭

- 每个根独立折叠/展开；折叠只改变侧栏视图，不改变活动根、Tab、session 或磁盘。
- 根右键提供复制路径和关闭工作区。关闭只移出本窗口的打开集合，保留最近项、已开 Tab 和磁盘文件。
- 文件与目录右键提供复制绝对路径；复制只写系统剪贴板，不修改文件。

### 3. 文件与目录删除一律进入系统废纸篓

- 文件和目录右键可请求删除；应用先显示明确、可取消的确认。若目标范围含 dirty session，确认文案必须说明未保存内容也会被丢弃。
- Rust 命令接收 `workspaceRoot + path`，规范化两者并要求目标是该根的严格后代、仍存在且为文件或目录。工作区根本身和根外路径始终拒绝。
- 成功后使用操作系统回收站/废纸篓，而不是永久 `remove_file/remove_dir_all`。失败保留原文件、dirty session 和树状态。
- 成功后刷新所属树，并从 session 与 Tab 的 current/back/forward 中移除已删除路径；若某 Tab 没有剩余历史才关闭并回到相邻 Tab 或 Welcome。
- 这不是重命名、移动、复制文件内容、批量文件操作或通用 VFS；这些仍需新需求另行决策。

### 4. 国际化与接口

- 折叠/展开、复制路径、关闭工作区、移到废纸篓、删除确认、成功/失败状态和 dirty 关闭对话框均同时提供 `zh-CN` 与 `en-US`。
- 新增单一 Tauri 命令 `move_workspace_entry_to_trash(workspaceRoot, path)`；命令总数由 11 增为 12。前端仍负责工作区状态和确认，Rust 只验证边界并执行可恢复移动。

## 不变量

1. 任意 dirty session 只要仍被 Tab 当前项或历史项引用，就必须有可见未保存状态并在关闭前获得用户决定。
2. 取消关闭或删除不得改变正文、Tab、工作区集合或磁盘。
3. 工作区根不能通过删除动作进入废纸篓；关闭工作区与删除磁盘内容是两个明确不同的动作。
4. 删除失败不得清理 session 或伪造树刷新成功。
5. Markdown/文本文件仍是正文唯一持久化真相；不新增服务端、账户、遥测、任意 pane 或通用文件管理框架。

## 最低验证

1. 编辑 `00`，同 Tab 导航到 `01`：Tab 仍显示 dirty；关闭 Tab 的取消保持内容，确认后关闭。红色关闭和 `⌘Q` 同样可取消、可确认且不留下进程。
2. 两个工作区根可分别折叠；根右键复制路径和关闭工作区，关闭后另一根与已开 Tab 保持。
3. 文件/目录复制路径得到精确绝对路径。删除确认取消时目标保留；确认后目标进入系统废纸篓并刷新树。
4. 删除工作区根、根外路径和不存在路径均拒绝；模拟废纸篓失败时目标、dirty 与 UI 状态保持。
5. 删除当前或历史引用的文件后不留下失效 session/history；剩余历史可继续导航，最后一个 Tab 可关闭到 Welcome。
6. 上述动作在中文与英文下都有完整文案；触摸板右键/Control-click 一次打开目标菜单且不先触发普通打开。
