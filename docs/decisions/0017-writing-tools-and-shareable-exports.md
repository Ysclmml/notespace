# ADR-0017：写作工具与可分享导出

- 状态：Accepted
- 日期：2026-09-03
- 取代：ADR-0016 中图片保留本地引用、Mermaid 仅源码及不获取导出资源的限制；ADR-0013 的当前页只查找范围扩展为可撤销替换。

## 背景

用户要求一次完成搜索高亮、可分享 HTML/PDF、可配置格式快捷键，以及当前页替换、文件收藏、专注模式、文档模板。导出必须在接收方电脑离线可读，而非只在来源电脑可用。仍是单用户本地编辑器，不增加账户、服务端或上传。

## 决策

### 分享文件

1. 导出捕获当前 normal Markdown 的最新内存正文，不执行保存、不改 dirty/Undo，不使用编辑器 DOM 或只导出可见范围。source-only 暂不导出，解析前沿用 8 MiB UTF-8 正文预算。
2. 单文件 HTML 自带样式、图片与静态 Mermaid SVG；不需要应用、CDN 或 JavaScript。GFM 表格、代码、中文和锚点保留；原始 HTML 仍转义。内部文档链接不递归打包，不声称是整工作区分享。
3. 导出对话框选择 HTML/PDF；本地图片默认打包。远程 HTTP(S) 图片必须用户勾选「下载并嵌入联网图片（仅本次导出）」后获取，默认关闭且不持久化。只执行本次导出引用的图片 GET，不携带用户登录 cookie、不上传正文、不预抓取、不后台重试。
4. 前端提交图片 token 和源地址；Rust 有界读取并将字节嵌入最终文件，图片 Base64 不送回 JS，不进入 Markdown/剪贴板 IPC。这是独立导出产物的编码，不放松三项编辑护栏。
5. 最多 128 个不同图片、每图 16 MiB、总图片 48 MiB、最终 HTML 80 MiB；位图须实际解码，单图最多 3200 万像素/128 MiB 解码数据。单远程图片 15 秒、资源批次 60 秒。Mermaid 最多 64 图、每图 SVG 4 MiB、单图等待 15 秒、整体等待 60 秒。不能解析、缺失、格式不支持、超限或图表失败，均明确失败且不输出缺图的“成功”文件。SVG 图片不得依赖外部资源或活动内容。
6. 当前 PDF 使用 macOS 原生 WebKit/打印分页生成 A4 PDF，正文是文字，不是整页截图。专用隐藏、禁脚本的导出视图与编辑器隔离；使用临时文件并清理，仅全部成功后原子写目标。Windows/Linux 的 PDF 入口暂禁用并明确说明，不通过外部服务、系统浏览器或新增 Chromium/Python 运行时伪装支持。
7. 两种导出均使用原生保存位置选择器，取消不落盘；拒绝覆盖源文档、当前已开文件、图片来源、错误扩展名及符号链接目标，沿用同目录原子写。分享成功不意味着发布到互联网。

### 格式快捷键

- 默认 `Mod`：macOS 为 Cmd；Windows/Linux 为 Ctrl。仅活动 Markdown 编辑器处理，不作用于设置/查找输入、代码文件、只读浮层或图片查看器；IME、AltGraph 和额外修饰键不误触。
- 默认 `Mod+1…6` 对所在/选中段落设置 H1…H6，`Mod+0` 正文；不是 Word 字号。`Mod+B/I/E` 为粗体/斜体/行内代码，`Mod+Shift+X` 删除线，`Mod+Shift+B` 引用，`Mod+Alt+C` 代码块。
- 可视和源码表面语义一致，变更经过普通可撤销事务。自定义/清除后移除库内旧绑定，不只叠加新快捷键。
- `settings.shortcuts` 本地持久化，旧设置自然补默认。设置支持动作搜索、组合录入、占用/保留快捷键冲突提示、清除、单项和全部恢复默认。常规应用/系统编辑键保留，不建设全局快捷键管理器；格式菜单展示实际配置。

### A–D 写作便利功能

- A：当前页查找栏可展开替换；字面、不区分大小写的单项/全部替换，仅当前活动编辑实例。可视处理可见文本，源码/代码处理源文本，二者匹配数量可不同。全部替换是一个 Undo 事务，纯查找不 dirty；只读预览不允许替换。单次替换最多 10,000 处，结果大小不超过原长度与 16 Mi UTF-16 字符中的较大值；保留 IME 与 Base64 防护，不做正则或跨文件批改。
- B：收藏独立于临时/固定标签，最多 100 个路径，每路径最多 4096 字符；不存正文，不自动扫描收藏文件。可收藏已保存 Markdown/代码文件，通过侧栏打开并遵循现有预览与 dirty 规则。关闭标签/工作区不移除收藏，失效路径提示错误后仍可手动取消；成功 Save As 跟随迁移。`markdown-workspace.favorites.v1` 是可丢弃的本机便利状态。浏览器演示收藏只在内存保留。
- C：专注模式 `Mod+Shift+Enter` 隐藏工具栏、侧栏、标签及状态栏，保持编辑器挂载、选区、Undo 和分组。提供常驻退出按钮；Esc 优先关闭查找/弹窗/菜单，再退出专注。工作区搜索退出专注显示侧栏。模式不持久化，不改正文，也不加入打字机滚动。
- D：会议记录、工作周报、技术方案三个双语内置模板。选择后在当前组创建独立 dirty 未命名 Markdown，正常 Save As；不覆盖当前文档，不存私有格式，不自动展开外部模板或执行宏。取消不创建文件/标签。

## 验证

搜索的 Unicode 高亮与安全文字；快捷键默认/改绑/清除/冲突/两平台/IME；三个可编辑表面的替换与一次撤销；收藏路径持久化和失效/取消；模板新建/dirty/不覆盖；专注进出/焦点/弹窗优先级。导出覆盖最新草稿、媒体预算、图片/图表/缺失资源、联网逐次授权、原子失败与目标保护，并以合成文档实际生成 PDF 检查分页、中文、图形和可选择文字。运行当前修订完整本地门禁；发布与用户安装另行授权。
