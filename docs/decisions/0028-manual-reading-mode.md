# ADR-0028：手动阅读模式

- 状态：Accepted
- 日期：2026-09-05
- 依据：用户以阅读学习为主，要求防止正文误修改，并明确选择默认编辑、需要时方便切换阅读。
- 修订：ADR-0027 暂不增加阅读功能的边界；可视/源码双表面、保存、导航与本地文件规则保持。

## 决策

1. 桌面窗口默认编辑，顶部常驻“阅读 / 编辑”按钮，一次点击切换；专注状态也保留切换入口。阅读开关属于当前窗口，不持久化，不替用户改变启动默认。
2. 阅读保护作用于当前窗口所有 Markdown、源码和普通代码标签，包括随后打开或移入分屏的文件。保持切换前的表面，不重建正文，不改变选区、数值阅读位置或撤销历史；普通 Markdown 仍按既有默认进入可视表面。
3. 阅读状态禁止正文输入、输入法组合编辑、剪切、粘贴、拖入正文、格式、替换、表格/任务列表及图片/图表源码编辑。显式共享或磁盘重载仍可同步正文。切换前已经输入的组合草稿正常结算；迟到的图片插入不能在切回编辑后恢复。
4. 隐藏可视编辑工具、源码切换和替换入口，正文右键只保留复制、全选与链接/图片阅读动作。查找与设置等普通输入框仍可输入。选择文字、复制代码、查找、链接、目录大纲、分屏、收藏、图表/图片查看和导出保持可用。
5. 阅读不是保存动作；不清除 dirty、不丢弃先前修改，已修改正文的保存和最后引用关闭保护继续有效。干净正文在阅读状态不因误按保存触发写盘。不新增自动模式快捷键，以免误键解除保护。
6. 沿用现有编辑器的动态只读能力及事务入口约束，不增加整篇静态渲染、滚动位置补偿循环、网络服务或新的持久状态模型。搜狗输入使用原生光标及复杂块高度稳定修复保持。

## 验证

- 默认编辑与手动来回切换，当前表面/位置/Undo/已输入组合草稿保留。
- 可视/源码/代码三表面的正文修改入口均不能导致 dirty；查找、复制和共享正文同步可用。
- 阅读中的右键精简、替换隐藏，任务/图表/代码编辑不穿透；普通设置输入框不受影响。
- 新标签与分屏继续只读，返回编辑恢复原有功能；阅读不清除已有未保存修改。
