# ADR-0012：Markdown 固定标签策略与跨标签导航

- 状态：Accepted
- 日期：2026-09-02
- 修订：ADR-0003/ADR-0011 中顶部前进/后退只作用于当前 Tab，以及普通 Markdown 链接总在原 Tab 跳转的规则
- 保持不变：共享 DocumentSession、每 Tab 独立阅读位置和文档引用、dirty 关闭、水平编辑组、代码/图片专用预览与三项实用护栏

## 背景

用户报告前进/后退与 Markdown 文档跳转失效，并明确要求：只将 Markdown 文档链接作为文档间跳转；当前标签固定则新开页面，未固定则在当前页替换；前进/后退可以跨标签。此前预览替换清空 Tab 历史，工具栏只读取当前 Tab，且本地 Markdown 解析要求来源/目标都已列入文件树，导致独立文件、新文件和跨工作区链接无法可靠使用。

## 决策

1. `.md` / `.markdown`（不区分大小写）本地链接和同文档 heading anchor 进入应用导航。相对链接以实际来源 Tab 的文档目录解析，支持绝对路径、file URL 和编码路径/fragment。显式 Markdown 路径不要求出现在工作区树；文件读取失败保留当前页和历史。省略扩展名或目录 index 仅在现有树有对应 Markdown 文件时补全，不将代码/图片后缀猜成 Markdown。
2. 普通跨文档点击：未固定标签在原 Tab 替换；已固定或已编辑标签保持，目标在原编辑组新建斜体预览标签，后续普通链接可替换这个预览。已有其他预览时将其固定，避免丢弃原页及其历史。同文档 anchor/Outline 不新建标签。显式 `⌘`/中键后台和 `⌘⇧` 前台新 Tab 手势保持不变。
3. 顶部前进/后退使用窗口内有界访问轨迹 `navigation: { visits: { tabId, entry }[], index }`，最多 200 项，只保存文档引用和视图，不复制正文、不持久化。实际前台打开、临时页替换、标签/编辑组切换和显式 anchor/Outline 定位记录访问；后台打开、输入、被动滚动、选择、固定标签及无变化的焦点事件不新增访问。
4. 遍历轨迹时恢复目标 Tab 所在的当前编辑组、文档、模式与已保存位置，不追加访问。后退后新导航截断窗口前进轨迹。各 Tab 仍保留独立文档引用和视图；临时替换不再清空此前引用，以保证返回和全历史 dirty 保护。
5. 关闭标签或成功删除文档时清理相应窗口轨迹，不因后退重建关闭的 Tab 或复活被删除/已放弃内容。窗口轨迹不额外拥有 session，不阻止既有最后 dirty 引用关闭；Save As 同步迁移窗口轨迹中的路径。
6. 异步导航捕获源 Tab/组；源关闭/移走、更新的同组请求或窗口前进/后退使旧原位导航失效。读取结束可以更新原组，但不得抢回用户之后聚焦的另组；焦点保持通过 action 明确表达，不先激活再切回产生虚假访问。
7. 可视正文链接、Crepe 链接悬浮卡片和源码链接统一回调应用路由。代码/文本仍走浮层/右侧只读预览，图片走图片查看器；这些预览不替换 Markdown 或写入文档浏览轨迹。外部网页仍交给外部浏览器，不新增抓取或网络能力。

## 最低验证

- 固定源 → 新预览、预览 → 原位、编辑后固定、同文档 anchor/Outline、修饰键后台不抢焦点。
- 链接和树预览替换后的后退/前进；跨标签/组恢复；重复 focus 无虚假记录；新导航截断 forward。
- 轨迹数量上限、关闭/删除过滤、Save As 迁移、共享正文和最后 dirty 引用提示。
- 独立文件、树未收录文件、相对/绝对/file URL、编码与跨工作区；非 Markdown 不被内部路由截获。
- 真实可视/源码编辑器点击及可视 hover 卡片，链接导航不改正文；旧异步结果不能覆盖历史恢复或夺取分屏焦点。

## 明确不做

不实现语义代码导航、跨窗口历史、关闭标签恢复、持久窗口快照、网络文档抓取或新依赖。
