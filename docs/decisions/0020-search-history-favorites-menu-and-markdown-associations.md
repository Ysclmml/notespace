# ADR-0020：搜索历史、收藏关闭菜单与 Markdown 文件关联

- 状态：Accepted
- 日期：2026-09-04
- 取代：ADR-0019 中收藏标题右键立即隐藏的交互；补充 ADR-0016/ADR-0019 的全文搜索便利状态和桌面文件打开入口。

## 背景

全文搜索弹窗关闭后丢失上次条件，重复查找时需要重新填写范围、大小写、正文正则和文件筛选。收藏分组虽然可以隐藏，但标题右键直接执行隐藏缺少明确选择，容易误触。打包后的桌面应用还应能由系统「打开方式」接收常见 Markdown 文件，而不要求用户先进入应用再使用文件选择器。

这些能力都只应增加本机入口和便利状态，不改变 Markdown 正文、工作区扫描、收藏路径或保存冲突规则。

## 决策

### 全文搜索历史

- `markdown-workspace.search-history.v1` 最多保存 12 条成功提交并由后端正常返回的搜索条件：正文查询、当前范围、大小写开关、正文正则开关、文件名/相对路径筛选及最后使用时间。相同完整条件只保留最新一条。
- 历史不保存匹配结果、行号、上下文片段或文件正文。读取失败、损坏、越界或 storage 不可用时回退为空，不阻断搜索。
- 点击历史项只回填表单，不自动读取磁盘；用户仍须明确提交。若原单根范围已不在当前打开工作区中，回填时降级为「全部已打开工作区」。用户可一次清空全部搜索历史。
- 既有磁盘搜索边界不变：未保存正文不参与，不引入持久索引、后台扫描或跨文件修改。

### 收藏关闭菜单

- 收藏标题普通左键仍只折叠/展开。右键或 Control-click 打开紧凑上下文菜单，只有用户明确选择「关闭收藏」后才把 `showFavorites` 设为 `false`；不再由右键动作直接隐藏。
- 点击外部、再次右键、滚动、缩放或 Esc 关闭菜单；键盘触发后焦点进入菜单，Esc 返回标题。收藏文件行的右键不关闭收藏。
- 关闭仍只改变分组可见性，不清空 `markdown-workspace.favorites.v1`，不删除文件、不关闭标签，也不丢失失效状态；设置页可重新显示。

### Markdown 文件关联

- 桌面包声明自己可编辑 `.md` 与 `.markdown`，使用标准 Markdown MIME/UTI 元数据。该声明让应用出现在系统「打开方式」中；是否设为系统默认应用由操作系统和用户决定，应用不静默接管默认关联。
- 启动参数中的受支持 Markdown 路径进入一个最多 32 项、单路径最多 4096 字符的本机待打开队列；macOS 同时接收 Tauri `RunEvent::Opened` 文件 URL。其他后缀、非文件 URL、重复待处理路径和超限输入被忽略。
- 原生侧发出不含路径或正文的 `opened-document-paths-available` 信号；前端通过新增 `take_opened_document_paths()` 命令清空读取队列。监听先注册再首次读取，并在后续信号到达时串行读取，避免应用冷启动期间丢失打开请求。
- 路径按收到顺序使用既有 `open_document` 预检和前台新标签策略打开。文件仍可作为独立文件，不隐式打开父目录工作区；已有会话、dirty、保存、外部变化和失败提示继续走统一规则。
- 新增一个实际 Tauri 命令后，当前共 27 个命令；原生菜单动作仍为 19 个。不为文件关联增加正文 IPC、常驻索引、网络请求或通用事件总线。

## 验证

覆盖搜索历史的成功写入、完整条件去重、12 条上限、坏 storage、手动清空、缺失范围回退和「回填但不自动搜索」；收藏标题右键/Control-click 的菜单打开、明确选择关闭、Esc/外部关闭、左键折叠及文件行不误触；`.md/.markdown` 大小写后缀、相对启动参数、去重/数量/长度边界、macOS 包内关联元数据、冷启动首次读取、后续事件、顺序打开和卸载监听。最终门禁与桌面包核验记录在本地交接，不以本 ADR 代替实际测试。
