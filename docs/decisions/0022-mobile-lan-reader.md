# ADR-0022：局域网移动阅读器与可信配对

- 状态：Accepted
- 日期：2026-09-04
- 补充：ADR-0005 的“桌面、本地、无服务端”边界；仅在用户明确开启时增加同一局域网内的只读共享能力。既有桌面编辑、保存、导出和更新检查规则不变。

## 背景

用户希望在 Android 手机上浏览桌面 NoteSpace 已打开的工作区，但不希望把手机变成完整 Markdown 编辑器，也不希望依赖手机浏览器、云同步或公共服务器。手机和电脑通常处于同一局域网；电脑仍持有 Markdown、文本和图片文件的唯一持久化真相，手机主要承担目录浏览、全文搜索和沉浸阅读。

局域网并不天然可信。一个未经认证、可读取任意路径的 HTTP 文件服务会把本地文档暴露给同网段设备；让手机 WebView 从电脑加载 HTML/JavaScript 也会扩大执行边界。因此移动端必须是 UI 随安装包发布的真实 App，电脑只返回有界的文档数据，并在发布前完成设备身份、加密传输和路径隔离验证。

## 决策

### 产品与技术形态

- 新增 Android 优先、随后可构建 iOS 的 **NoteSpace Mobile**。它是 Tauri 2 + React/TypeScript 的独立移动应用表面，不是 PWA、浏览器壳或桌面编辑器的缩放版。
- 移动 UI、Markdown 渲染器和 Mermaid 运行时代码随 App 本地打包。电脑不得向手机下发可执行 HTML、JavaScript、CSS 或 WebView 页面；Markdown、目录、资源和搜索结果始终作为数据返回，并由 App 内白名单渲染器处理。
- 桌面端继续使用现有 Tauri/Rust 应用，在用户明确开启后运行一个进程内的只读 HTTPS/WSS 服务。移动端的联网、证书固定、令牌存储和重连由移动 Rust/native 层承担，不依赖 WebView `fetch` 绕过证书校验。
- 选择 Tauri Mobile 是为了复用 React 阅读体验、Rust 协议和安全传输代码。Capacitor 可作为动态证书固定或移动插件真机验证失败时的备选；React Native/Expo 会迫使当前 DOM Markdown/Mermaid 阅读表面重写，同时仍需自建 TLS、扫码和局域网发现原生模块，因此不作为首选。

### 桌面共享边界

- 共享默认关闭。用户在桌面端开启「移动访问」并从**当前已打开工作区**中明确选择共享根；关闭开关、退出桌面应用或移除某个根后，对应访问立即停止。
- 首版只读取磁盘上已保存的正文，不传输未保存草稿、Undo、标签历史、模板目录、最近路径、应用设置或电脑账户信息。手机明确显示「以电脑磁盘内容为准」。
- 协议只提供状态、工作区列表、逐层目录、文档、文档引用资源、收藏投影、有限全文搜索和变更通知；不提供保存、上传、创建、重命名、移动、删除、命令执行或通用文件 API。
- API 使用随机、不透明的 workspace/document/asset ID。响应不包含电脑绝对路径；显示路径仅为所选根下的规范化相对路径。
- 每次访问均从已登记根出发执行规范化和真实路径校验，拒绝根本身之外的路径、`..` 穿越、符号链接、隐藏项、重目录、设备文件及不支持的文件类型。内部 Markdown 链接和图片引用也必须重新经过同一授权解析，不能把客户端传入值当文件路径。
- 沿用全文搜索的有限扫描思想。移动目录和读取另设硬预算：最多共享 16 个根、单次树扫描 20,000 项/64 层、单篇 Markdown 2 MiB、单资源 16 MiB、搜索最多 5,000 文件/64 MiB/200 个匹配；达到边界或部分不可读时返回明确的不完整状态。

### 配对、身份和传输

- 桌面首次开启时生成本机实例身份和 HTTPS 证书。二维码包含协议版本、实例 ID、局域网地址候选、随机端口、一次性短期 nonce 与证书/SPKI 指纹，不包含工作区路径或正文。
- 手机扫码后先在 Rust/native 网络层固定并验证证书指纹，再提交一次性 nonce。桌面显示待配对设备和校验短码，只有用户确认后才签发逐设备、可撤销的高熵令牌；nonce 使用一次即失效并有较短过期时间。
- 后续请求同时要求已固定的电脑证书和逐设备令牌。桌面端可查看并撤销设备；令牌只存于移动系统安全存储，不写入日志、二维码历史、URL 查询串或 WebView localStorage。
- mDNS/DNS-SD 以后只用于发现已配对电脑和地址变化，不能替代证书身份或令牌认证。首版必须保留二维码和手动地址/配对码入口。
- 不做 UPnP、端口映射、公共隧道、云中继、账号登录、遥测或公网访问。生产构建禁止明文传输和跳过证书验证。
- 为尽早验证 Android 工程，开发构建可提供显著标记的 `debug` 明文回环/局域网原型，但必须同时满足：编译期仅 Debug 可用、共享默认关闭、随机一次性口令、只读和所选根隔离。它不构成可发布能力；Release 在证书固定完成前必须拒绝启动共享。

### 移动体验

- 首次进入显示已配对电脑、扫码和手动连接；连接状态明确区分正在连接、在线、电脑离线、授权失效和协议不兼容。
- 手机使用「浏览 / 搜索 / 收藏 / 最近」四个底部入口。浏览采用逐层目录列表和面包屑，不照搬桌面常驻文件树；平板宽度可用目录与正文双栏。
- 阅读页提供返回、标题、可折叠大纲、字号/行高/主题、阅读进度和重新连接。GFM 表格与代码块局部横向滚动；图片和 Mermaid 懒加载并支持全屏缩放；内部 Markdown 链接保持 App 内导航，外部 HTTP(S) 链接仅在用户点击后交给系统浏览器。
- 搜索保留本次会话的条件、结果、滚动和最后访问项；结果按文件组织并跳到匹配行。收藏来自桌面共享投影且首版只读；最近阅读和每篇滚动位置仅保存在手机本地。
- 断线后已渲染的当前文档留在屏幕，目录、搜索和新资源读取暂停并可重试；后台重连成功后不抢走阅读位置。
- MVP 不持久缓存正文、图片或搜索片段。以后若增加离线文档包，必须由用户逐工作区明确下载、展示占用空间并可一键清除，另行决策加密与过期规则。

## 实施阶段

1. **工程与阅读壳**：生成 Android Tauri 工程、移动专用入口、模拟传输和核心浏览/阅读 UI，产出可安装的 Debug APK。
2. **只读纵向链路**：桌面显式开启 Debug 共享，手机通过手动地址/一次性码读取一个测试工作区，验证路径边界、正文渲染、资源和搜索。
3. **可信配对发布门槛**：完成二维码、电脑确认、逐设备撤销、HTTPS 证书固定、安全存储、前后台重连及 WSS/SSE 变更通知；随后才允许 Release 局域网共享。
4. **跨平台收尾**：Android 真机作为首要验收；iOS 补充 `NSLocalNetworkUsageDescription`、Bonjour 声明、相机说明和完整 Xcode 真机验证。

## 验证

- 自动测试覆盖不透明 ID、根外/符号链接拒绝、隐藏和类型过滤、读取/搜索预算、一次性 nonce、令牌撤销、未授权请求、Markdown 白名单渲染、断线状态及移动导航/位置恢复。
- Android 至少覆盖 API 24 最低版本与当前 targetSdk 模拟器，并在真实 Android 手机验证扫码、Wi-Fi 地址变化、后台恢复、大文档、表格、图片和 Mermaid。
- 发布前必须抓包确认没有正文外发、绝对路径或 URL 令牌泄漏；验证错误证书、错误指纹、过期二维码、被撤销设备和同网段未配对设备全部无法读取。
- 动态证书固定、Android 局域网权限演进、iOS ATS/Local Network 权限和 16 KiB native page alignment 是硬门槛。任一项未通过时保留 Debug 原型，不把明文或 `acceptInvalidCerts` 作为降级发布方案。

## 结果

该方案保留“Markdown 文件在电脑上是真相”的简单模型，同时提供真正的移动 App 阅读体验。代价是桌面端首次拥有一个受控的局域网监听面，并需要维护移动构建和配对生命周期；这些复杂度被限制在显式开启、只读、所选根与严格发布门槛之内，不扩展成云同步或远程文件管理器。
