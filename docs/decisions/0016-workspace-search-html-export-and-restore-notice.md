# ADR-0016：工作区搜索、HTML 导出与恢复提示

- 状态：Accepted
- 日期：2026-09-03
- 依据：用户要求继续完善日常编辑功能并发布小版本。
- 修订：ADR-0013 的查找范围仅限当前页；保持原有当前页查找、无正文快照及扁平编辑组规则。

## 决策

1. 启动恢复跳过的工作区与文档要显示非模态提示，列明路径，支持重试、选择工作区文件夹、从最近记录移除及关闭提示。不把“暂不可用”直接判断为删除，不自动重建目录，不迁移或批量修复链接；移除只影响便利记录。迟到恢复和重试不能覆盖用户新操作、复活已关闭标签或清除编辑缓冲区。
2. 工作区全文搜索通过明确提交查询读取当前打开根的磁盘文本，不建立持久索引，也不上传内容。沿用每根隐藏项、受支持文件、重目录与符号链接过滤；限制扫描文件、总读取字节、单文件大小和返回结果。界面说明搜索不包含未保存修改，明确显示截断、跳过和不可读根。当前页 `Cmd/Ctrl+F` 保持不变，工作区入口为 `Cmd/Ctrl+Shift+F`。
3. 搜索结果包含路径、行号与有限上下文；点击使用活动编辑组的临时标签策略，已固定或 dirty 的源页保留。按 Markdown 源码偏移定位可视页（尽力映射），代码按行定位，进入已有跨标签导航轨迹。文件在搜索后改变时打开最新磁盘或现有受保护缓冲区，行号可能偏移，不用旧搜索正文覆盖会话。
4. HTML 导出使用当前 Markdown 的最新文本（包括未保存修改），通过结构化解析生成静态阅读页。独立样式、GFM 表格、列表、代码、链接和图片地址保留；原始 HTML 不作为可执行标记，危险 URL 不导出。禁止导出编辑器工具栏、选区或依赖虚拟滚动的 DOM。Mermaid 第一版保留代码，不增加远程脚本或下载。
5. 导出使用独立的原生保存对话框和原子写入，只接受 HTML 后缀，拒绝覆盖正在打开的文件及原 Markdown；取消、写入失败不改变文档、dirty、Undo 或浏览状态。图片不打包、不后台请求；本地相对资源转为文件 URI，导出文件用于本机阅读，跨机分享需要自行携带并调整资源。未保存文档没有路径基准，不能伪造相对资源的有效位置。

## 验证

- 合成失效路径的启动、重试、移除、空白启动和迟到结果保护；原文件与当前编辑保持。
- 合成多根搜索的 CJK、大小写、隐藏项、重复根、病态输入、扫描/结果限制、错误与关闭保护；结果导航和分屏焦点。
- HTML 的完整结构、Unicode、GFM、危险 HTML/URL、资源地址；导出取消、后缀限制、已开文件保护与原子写入失败。
- 不引入重命名/批量改链接、PDF、持久搜索数据库、正文备份或发布自动化。
