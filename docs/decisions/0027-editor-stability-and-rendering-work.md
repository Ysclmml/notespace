# ADR-0027：编辑入口精简、正文生命周期与渲染稳定性

- 状态：Accepted
- 日期：2026-09-05
- 取代范围：补充 ADR-0006 的表面切换、ADR-0012/0014 的历史与文件身份、ADR-0019 的搜索投影，以及 ADR-0025/0026 的离线完整性和公式容器语义。

## 背景

用户要求移除可视正文左侧随鼠标显示的加号和块选择入口，结构编辑继续使用已有右键菜单。当前阶段优先修复内容正确性、撤销、长期浏览和渲染成本，不增加新的阅读功能。

## 决策

- 关闭可视编辑器 BlockEdit 功能及其鼠标跟踪，不再显示左侧加号或块选择/拖动控件。右键插入段落、格式和表格操作继续保留；源码与代码块的普通行号不受此决策影响。
- 同一 Tab、同一文档的已访问编辑表面保留各自的内存撤销历史。另一表面按首次访问创建，隐藏时暂停正文同步、焦点与视图上报，重新激活时先同步最新正文；对侧/外部同步不作为本表面的可撤销编辑，也不回传旧正文。关闭或更换文档销毁实例，不跨重启持久化 Undo。
- 数学规范化必须保留引用和列表容器，容器前缀不得成为公式体，同行显示公式不得脱离所在条目。首次可视编辑只能写回数学和容器语义等价的 Markdown。投影修改一次拼接，避免按每个公式重复复制全文。
- 原生打开以规范化的真实路径返回文档身份；保存已有别名也写入真实目标，不以原子 rename 替换符号链接本身。新 Save As 目标规范化父目录，原有打开目标冲突与磁盘版本检查继续有效。
- 窗口访问轨迹仍限 200 项；每个 Tab 的 back/forward 各保留最近 200 项，超出部分只保留仍被窗口轨迹需要或 dirty 正文必要的唯一引用。无引用 clean 正文回收；dirty 正文仍须在最后引用关闭时明确处理，不因回收策略丢弃。
- 外部变化元数据检查每批最多 1024 条，真实引用更多时分批执行。原生监听先合并工作区根和独立文件父目录，再限制最多 1024 个实际监听目标；超出部分仍由聚焦和 30 秒元数据检查兜底，不能让整批文件停止检查。
- 正则只在原生扫描执行。返回原行 UTF-16 列号/长度，同时返回实际截断片段内的 UTF-16 高亮起止位置；长匹配只高亮可见正文部分，不含省略号。前端只验证范围并绘制，不在渲染时再次执行用户正则。大纲仅在正文变化时重新提取，阅读位置变化复用已有投影。
- 手机目录保留 `truncated` 完整性状态并提示；任意目录不完整时拒绝发布新的离线候选，保留上一份完整快照。最近文件以电脑、稳定工作区 `syncKey` 和相对路径重新解析当前运行的 opaque ID，并迁移阅读位置；旧记录仅在名称唯一时兼容解析，不串入同名根。
- Android 普通 Debug/Release 均按生命周期持有 Wi-Fi 多播锁，遵循 ADR-0025 已接受的普通构建局域网发现能力。

## 验证与边界

使用合成内容覆盖容器公式及编辑后序列化、两种表面 Undo/Redo 和隐藏事件隔离、文件别名保存、超限历史和检查批次、UTF-16 截断高亮、离线候选失败保留和重启后的最近阅读。渲染测量应区分脚本、布局绘制与原生 I/O，不把局部微基准视作整机性能保证。

不增加网络范围、持久正文缓存、文件锁或通用同步框架。移动图片、Mermaid、链接导航与完整真机验收仍是独立未完成范围；本决策不将占位能力标为完成。
