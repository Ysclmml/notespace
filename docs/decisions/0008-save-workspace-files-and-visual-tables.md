# ADR-0008：保存策略、多根文件树与可视表格工具

- 状态：Accepted
- 日期：2026-08-31
- 修订：ADR-0007 中“侧栏只显示当前工作区”的呈现方式，以及 ADR-0006 中表格高级工具后置的范围
- 保持不变：ADR-0005 的精简本地应用边界和三项实用护栏；ADR-0006 的 Markdown 真可视/显式源码双表面；ADR-0007 的多工作区集合、最近项、可编辑代码/文本和单一右侧只读栏

## 背景

当前纵向切片已经能编辑 Markdown 与常见代码/文本、保留多个工作区并在关闭 dirty 文档时提示。继续实际使用暴露出四类日常摩擦：用户希望保留明确可控的手动保存，同时可以按需开启停止输入后的自动保存；多个已打开工作区需要在同一文件侧栏直接看见，而不只是通过切换器逐个查看；新建文件和在系统文件管理器中定位文件不应离开应用；大量 GFM 表格需要更接近普通文档软件的直接操作，而不是退回管道源码。

这些能力仍属于普通本地文本编辑器。它们不要求后台服务、文件监控中心、项目数据库、任意分屏、通用文件操作框架或新增安全平台。

## 决策

### 1. 默认手动保存，可选停止输入后自动保存

- 默认 `autoSaveMode` 为 `manual`。用户通过 `⌘S`/菜单保存；关闭 Tab、窗口或应用时，仍对所有被当前项或历史项引用的 dirty session 使用现有可取消提示。
- 设置可切换为 `afterDelay`，延迟 `autoSaveDelaySeconds` 允许 1–300 秒，默认预置值为 5 秒。输入继续变化时重置该文档计时器。
- 自动保存只处理已有磁盘路径的 dirty session。未命名 `untitled://` 文档必须先由用户 Save As，不自动弹出选择器。
- 计时器触发时必须核对 session 仍 dirty、路径仍已保存且正文仍等于排程文本；迟到计时器不得覆盖更新内容。切回手动模式、session 不再被引用或组件卸载时取消对应计时器。
- 自动保存复用 `save_document` 和同目录原子保存。成功清除对应 dirty 并显示自动保存状态；失败保留 dirty 和具体错误，因此后续关闭仍会提示。
- 自动保存偏好写入现有本机 settings；它不是文档元数据、后台 daemon 或崩溃恢复日志。

### 2. 文件侧栏同时展示全部已打开工作区根

- 一个窗口继续维护多个工作区；文件模式侧栏按打开顺序同时渲染每个根及其独立文件树，活动根使用明确视觉状态。
- 点击根标题或其中任一文件会激活该根；Quick Open 仍聚合全部根，嵌套根的文件归属仍使用最长匹配。
- 顶部工作区切换器继续承担打开、激活、移除和最近工作区入口，但不再是查看非活动根文件树的唯一方式。
- 关闭工作区仍只移出窗口集合，不删除文件，也不关闭已打开主 Tab。侧栏不演变为项目数据库或远程文件系统。

### 3. 在工作区内新建文本文件，并在系统文件管理器中定位

- 每个工作区根和目录提供“新建文件”；未写扩展名时前端默认补 `.md`，显式扩展名则保留。
- Rust 接收 `workspaceRoot + directoryPath + fileName`：规范化工作区根和已存在父目录，要求父目录位于该根内、文件名是单一非空名称、后缀属于当前常见 UTF-8 Markdown/代码/配置/文本集合，并用 `create_new` 保证不覆盖。
- 不创建中间目录、不覆盖同名文件。成功创建空 UTF-8 文件后返回现有 `OpenDocumentResult`，前端刷新所属根并在前台主 Tab 打开。
- 工作区根、目录、文件和当前已保存文档可执行“在访达/文件管理器中显示”。macOS 文件使用 `open -R`、目录使用 `open`；Windows 使用 Explorer；Linux 文件打开父目录、目录使用 `xdg-open`。命令参数不经过 shell。
- 当前范围不包含重命名、移动、复制、删除、回收站或通用文件操作 API。

### 4. GFM 表格保持真可视，并提供局部结构工具

- 表格始终是 ProseMirror 的可编辑结构；单元格输入、选择、Tab/Shift-Tab、Undo/Redo 和 Markdown serializer 继续使用正常正文事务。
- 宽表格只在表格容器内部横向滚动，不挤压整页或扩大应用主布局。
- 用户可拖动列边界调整当前可视表面的列宽。`colwidth` 只属于编辑视图，不写入 Markdown、不标 dirty、不建立 sidecar；重开文档或重建表面可回到默认列宽。
- 表格工具提供可视网格选取行列数并插入表格；光标在表格内时可增删当前行/列。右键表格提供在前/后插入行列、删除当前行列和删除表格。
- 可视编辑右键同时提供普通结构动作：正文/标题、引用、列表、常用行内格式、代码块、水平分割线和表格插入。动作发出当前小型 editor command，并进入正常 Undo 历史；不建立通用菜单 DSL。

### 5. 新增用户界面必须完整中英文

- 自动保存设置与状态、工作区根/目录/文件动作、文件管理器定位、表格工具和结构右键必须同时提供 `zh-CN` 与 `en-US`。
- 原生菜单新增固定动作 `file.reveal`；Rust 只转发 action ID，当前文档路径和可用性仍由前端判断。
- 本轮 Tauri 命令总数由 9 增至 11：新增 `create_workspace_text_file` 与 `reveal_in_file_manager`。不生成未来命令或通用 IPC schema。

## 不变量

1. Markdown/文本磁盘文件仍是唯一持久化正文；自动保存只改变保存时机，不改变数据模型。
2. 手动模式是默认值；任何尚未成功落盘的 dirty session 都必须经过现有关闭确认。
3. 列宽是 view-only；拖动列宽不得改变 Markdown、dirty 或 Undo 正文历史。
4. 新建文件只发生在用户指定的现有工作区根/子目录，且绝不覆盖。
5. 同时展示多根不改变 `DocumentSession != Tab != HistoryEntry`、最长匹配 owner 或单一右侧只读栏。
6. 新菜单必须双语，但不得把前端状态复制进 Rust 菜单层。
7. 不新增 Ruby 工具链、网络、账户、遥测、IDE/LSP、任意 pane/grid 或重型安全机制。

## 最低验证

1. 默认手动模式保持 dirty；1 秒自动保存模式在停止输入后写盘，继续输入会重置计时，未命名文档不自动 Save As，失败仍 dirty 并在关闭时提示。
2. 两个工作区根及其文件树同时可见；点击非活动根文件会激活所属根并打开文档，移除根不删除文件或关闭 Tab。
3. 在根和子目录分别新建无扩展名 Markdown、显式 `.txt`/代码文件；刷新树并打开结果。越界父目录、路径式文件名、未知后缀和同名目标均拒绝，原文件不变。
4. macOS 文件/目录生成不同的 Finder 命令；Windows/Linux 映射有单测；adapter 精确转发 camelCase 参数，测试不真的启动文件管理器。
5. 宽表格内部横向滚动；拖动列宽后保存文本不变且不 dirty；网格插表、行列增删、删除表格、Undo/Redo、保存重开均正确。
6. 中文和英文下，自动保存、工作区文件动作、`file.reveal`、表格工具及结构右键都有对应文案和可访问名称。

## 后果与明确不做

- 文件侧栏信息密度提高，但仍是多个轻量根的线性集合，不是多项目数据库。
- 自动保存是可选的前端 inactivity timer，不提供周期保存、版本历史、快照或后台恢复。
- 表格列宽无法在纯 GFM Markdown 中可靠表达，因此明确不持久化；若未来需要持久列宽，必须单独决定兼容格式，不能静默写私有 HTML/元数据。
- 文件新建与 reveal 解决当前日常动作；重命名、删除、移动和目录创建按真实需求另行决策。
