# ADR-0019：搜索筛选、收藏显示与 GitHub 更新检查

- 状态：Accepted
- 日期：2026-09-04
- 取代：ADR-0018 中全文搜索范围控件和收藏分组显示方式的对应部分；其他搜索、收藏、模板、帮助与导出边界不变。

## 背景

联合验收继续暴露三项日常摩擦：原生范围选择器在长工作区路径下不易阅读；正文搜索缺少正则和独立文件筛选；收藏分组无法暂时隐藏。应用也需要在不引入自动更新器的前提下，让用户知道 GitHub 上是否已有新版本。

更新检查是用户明确提出的有限网络能力，因此必须固定来源、内容和触发方式，不能借此扩展为任意更新源、后台下载或文档遥测。

## 决策

### 全文搜索

- 工作区范围使用应用自绘的单选范围控件，列出「全部已打开工作区」和每一个当前已打开根；支持键盘移动、选择、Esc、点击外部关闭和完整路径提示，不依赖平台原生下拉框的宽度与样式。
- 正文查询默认仍是普通文本，可独立开启正则表达式并沿用区分大小写选项。另有一个独立、忽略大小写的「文件名或路径筛选」正则，匹配工作区相对路径（因此同时覆盖目录和文件名），不把筛选文字当正文查询。两个正则无效时分别提示，不启动一次伪成功扫描。
- 搜索仍只读取已打开工作区内受支持 Markdown、代码和文本的磁盘正文，不包含任何未保存修改。快速打开继续只找文件名/路径，当前页查找继续消费当前编辑表面，三者语义不合并。
- Rust 后端继续执行有界扫描：最多 32 根、20,000 个目录项、5,000 个文件、单文件 2 MiB、总读取 64 MiB、64 层深度和 200 个匹配行；正文查询最多 512 字符，路径筛选正则最多 256 字符。隐藏项、重目录、后缀、符号链接、UTF-8 和迟到结果保护保持不变；达到边界或部分不可读必须报告结果不完整。

### 收藏显示

- `showFavorites` 是 `markdown-workspace.settings.v1` 中默认开启的普通布尔设置。设置页可隐藏或重新显示文件侧栏顶部的收藏分组。
- 收藏分组标题的右键或 Control-click 立即关闭 `showFavorites`；标题普通左键只折叠/展开，收藏文件行的右键或 Control-click 不触发隐藏。标题提供对应的双语悬停提示，并阻止侧栏或工作区右键菜单误开。
- 隐藏只改变分组可见性，不清空 `markdown-workspace.favorites.v1`、不删除磁盘文件、不关闭标签，也不停止收藏路径迁移和失效记录保留。重新开启后显示原有收藏。

### GitHub 更新检查

- 原生 `check_for_update()` 只向固定端点 `https://api.github.com/repos/Ysclmml/notespace/releases/latest` 读取最新稳定发布信息，并以当前应用包版本比较。请求有 10 秒总超时、1 MiB 响应上限且不跟随重定向；404 表示尚无发布，失败只显示提示，不阻断本地编辑。
- `checkUpdatesOnStartup` 是默认开启的普通布尔设置；用户可在设置中关闭启动检查。启动检查只在应用启动时执行，不轮询。About 始终显示当前版本，并允许用户明确点击后手动检查。
- 检测到更高稳定版本时显示当前版本、最新版本和操作选择。「跳过此版本」只记住该一个版本；以后更高版本仍可提示。「稍后提醒」不写入跳过记录。
- 发布页只在用户点击「查看/打开发布页面」后交给系统浏览器。GitHub 返回的地址必须是 `https://github.com/Ysclmml/notespace/releases/...`；不接受响应中的其他主机或协议。
- 当前新增一个 `check_for_update()` Tauri 命令，总数为 26。既有 `open_external_url(url)` 继续承担用户手势后的系统浏览器打开，不增加自动安装命令。

### 网络与数据边界

- 不自动下载或安装更新，不替换应用包，不请求管理员权限，不接受用户输入或远端下发的任意 API/更新源。
- 更新请求不携带文档正文、工作区路径、收藏、模板、最近项、设备账户或遥测事件；仅使用固定 GitHub API 所需请求头和应用版本 User-Agent。没有账户、token 或后台上传。
- 断网、GitHub 限流或无发布时，编辑、保存、搜索、收藏、模板和离线帮助继续可用。除 ADR-0017 每次导出显式授权的联网图片与本 ADR 固定更新检查外，不新增后台网络活动。

## 验证

覆盖自绘范围控件的鼠标、键盘、长路径和范围切换迟到保护；普通/正则正文、独立路径筛选、无效正则、Unicode/大小写和所有扫描预算；收藏设置持久化/恢复默认、标题右键与 Control-click、普通左键/文件行不误触及隐藏后数据保留；固定 GitHub 端点、稳定版本比较、404/失败、响应预算、重定向和发布页校验；启动开关、单版本跳过、About 手动检查及用户手势打开。最终门禁和桌面网络/离线验收记录在本地交接，不以本 ADR 代替实际测试。
