# ADR-0021：全文搜索会话与桌面界面本地化收尾

- 状态：Accepted
- 日期：2026-09-04
- 取代：ADR-0020 中固定 12 条搜索历史的上限；补充 ADR-0019/ADR-0020 的搜索弹窗、原生菜单与更新检查体验。

## 背景

全文搜索结果用于连续查看多个匹配文件。若点击一条结果后销毁整个搜索界面，用户再次打开全文搜索时会丢失结果、滚动位置和刚才查看到的位置，只能重复扫描。最近搜索卡片展示范围文字也占用过多空间，范围下拉箭头过小。另一方面，搜索历史数量需要由用户控制，但仍须有硬上限；macOS 自动补入编辑/窗口菜单的项目和 About 更新状态变化也需要与应用语言、稳定布局保持一致。

这些调整属于界面与本机便利状态，不改变磁盘扫描、正文保存、更新源或隐私边界。

## 决策

### 全文搜索会话

- 在一次应用运行期间，全文搜索保留最近一次表单、已提交结果、结果区滚动位置和最后激活的匹配。点击结果仍关闭弹窗并在活动编辑组打开目标；再次打开全文搜索时直接回到该结果和位置，不自动重新扫描磁盘。
- 搜索弹窗隐藏期间不得保留遮罩、焦点陷阱或键盘拦截；重新打开时恢复可操作焦点，并让最后激活的结果具有可辨认状态。工作区或条件发生变化后，只有用户再次提交才产生新结果。
- 结果、上下文片段、滚动位置和最后激活项只存在当前前端内存中，退出应用后清空，不进入 `localStorage`、浏览恢复或 Markdown 正文。

### 最近搜索与设置

- 最近搜索卡片采用紧凑尺寸，视觉上只显示查询文字；范围、大小写、正文正则和文件筛选仍保留在记录数据中，并可通过可访问名称或提示说明，不用范围副标题占据列表空间。
- `AppSettings.searchHistoryLimit` 默认 15，允许 1–30 的整数。设置值损坏或越界时归一化；降低数量后立即裁剪 `markdown-workspace.search-history.v1`，以后写入也使用新上限。清空历史仍由用户明确触发。
- 历史继续只保存成功搜索条件并去重，不保存结果或正文；选择历史只回填条件，不自动读盘。范围选择器使用尺寸清晰的应用自绘 SVG 箭头和完整点击区域，不退回平台原生下拉样式。

### macOS 菜单与 About

- 应用负责创建的菜单项继续随 `zh-CN/en-US` 设置即时重建。macOS 自动插入的编辑、窗口管理项目通过应用包声明并随包提供的本地化资源显示对应语言；不通过菜单标题遍历、私有 API 或易受系统版本影响的运行时替换来修改系统项目。
- 系统自动项目的语言遵循 macOS 对该应用选择的语言，并在应用重新启动后完整生效；应用内即时语言切换只承诺应用自有菜单项同步更新。
- About 的更新状态使用稳定的预留区域。未检查、检查中、最新、无发布、新版本和失败状态不改变对话框外框高度；长错误在区域内安全换行或滚动，不遮挡关闭、重试或发布页动作。

## 验证

覆盖搜索结果跳转、关闭后无交互遮罩、重新打开时表单/结果/滚动/最后激活项恢复且不重复调用后端；新搜索替换旧会话，退出后不持久化结果。覆盖紧凑历史、只显示查询文字、默认 15、1–30 归一化、降低上限立即裁剪、坏 storage、清空与只回填。覆盖范围箭头的可见尺寸、键盘与鼠标操作。macOS 包内本地化声明和资源须经最终 `.app` 核验；应用自有菜单双语测试保持通过。About 覆盖全部更新状态及长错误，外框尺寸稳定且动作可达。最终门禁与桌面包核验记录在本地交接，不以本 ADR 代替实际测试。
