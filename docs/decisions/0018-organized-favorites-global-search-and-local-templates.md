# ADR-0018：收藏分组、全局搜索与本地模板库

- 状态：Accepted
- 日期：2026-09-04
- 取代：ADR-0016 的侧栏全文搜索入口；ADR-0017 的独立收藏页和仅内置模板范围。其他编辑、搜索和导出边界不变。

## 背景

联合验收发现侧栏标签挤出第二行、收藏卡片与文件树不协调，全文搜索、帮助和自定义模板入口不清楚。用户要求右键收藏、明确失效路径处理、独立搜索入口、可找到的功能帮助、本地模板文件和导出二级菜单。

## 决策

### 收藏

- 文件侧栏只保留「文件 / 大纲」切换。「文件」页顶部为可折叠的收藏组，显示星标、数量和紧凑文件行；短父目录提示辅助区分，完整路径在悬停提示中展示，不铺满绝对路径卡片。
- 已保存文件可通过工具栏星标或文件树右键收藏/取消收藏；目录不提供收藏。最多 100 路径，兼容既有本地存储键，不复制正文、不关联标签固定状态。
- 所属工作区未打开时，直接按收藏路径作为独立文件打开，不自动打开整个工作区、不更改搜索范围。
- 文件缺失、移走或不可读时保留收藏并标记，提供重试与取消收藏。取消只移除便利记录，不删除磁盘文件；不猜测重命名、不自动修复或静默清理。
- 展开组、窗口重新获得焦点或重试后有界检查现存路径的元数据，忽略迟到结果。关闭工作区或标签不删除收藏；成功 Save As 仍迁移收藏路径。

### 全文搜索

- 工具栏「全文搜索」、更多菜单和 `Cmd/Ctrl+Shift+F` 打开独立宽弹窗，不属于侧栏标签；Esc 关闭，选择结果后回到活动编辑组并定位。
- 默认搜索所有**已打开工作区**的受支持 Markdown、代码和文本的**磁盘正文**，可切换到某一个已打开根。显示范围、片段、行号、高亮和扫描不完整提示。
- 不扫描整台电脑或关闭的工作区，不包含未保存修改，不建立持久索引；沿用 ADR-0016 的所有扫描、隐藏项、后缀和导航保护。
- 「快速打开」继续按文件名/路径寻找文件，当前页 `Cmd/Ctrl+F` 继续搜索当前编辑内容；三者入口和说明不混淆。

### 帮助和模板

- 「使用帮助」为随应用打包的双语离线指南：入门、写作、查找、收藏/模板、分享与快捷键速查；速查展示当前设置中的格式键。无需联网，也不创建文档或改变 dirty。
- 「关于」只保留产品/仓库信息，和帮助独立。原生 `help.open` 打开指南，新增 `app.about`；当前共 19 个前端菜单动作。
- 保留三个内置模板；「从模板新建 → 自定义模板」支持将当前 normal Markdown 最新正文复制成模板、刷新列表、打开模板文件夹和选用模板。
- 自定义模板放在 Tauri 当前应用标识对应的 `app_data_dir()/templates`，不放安装目录、工作区或 WebKit 设置。首次显式访问才创建/读取，普通 `.md/.markdown` 文件可由用户在本机备份、编辑和管理，Debug 与正式标识隔离。升级应用包不替换此目录。
- 当前只接受目录直属普通 UTF-8 Markdown，不跟随符号链接或递归扫描。最多列出 128 个模板、枚举 1024 项、每篇 256 KiB；读取前执行有界 UTF-8/长行/Base64 护栏，截断、跳过和错误明确展示。满库不允许保存一个无法显示的新模板。
- 保存模板使用单层合法名称、create-new、不覆盖已有文件，失败清理本次未完成写入。保存只是复制正文，不保存原文、不清 dirty；选用才在活动组创建普通 dirty 未命名文档。相对图片不会复制，保存新文档后由用户调整路径；不增加变量替换、模板脚本或资产搬运。
- 仅新增实际使用的 `list_document_templates()`、`read_document_template(path)`、`save_document_template(name, content)`，当前共 25 个 Tauri 命令；打开目录复用既有文件管理器入口。

### 导出

- 应用更多菜单和原生文件菜单均只保留一个「导出」父项，HTML/PDF 为二级选项，后续格式可并列扩展。
- 选择格式后仍进入既有导出确认/保存流程。平台可用性、联网图片逐次授权、独立可分享产物与原文保护全部沿用 ADR-0017。

## 验证

覆盖右键收藏、紧凑分组/折叠、工作区关闭后独立打开、失效保留/重试/移除与迟到检查；全局搜索范围、键盘焦点/关闭/结果导航；帮助与关于分离、当前快捷键展示；模板惰性访问、临时目录读写、大小/类型/同名保护、复制不保存源文档；导出二级入口及键盘操作。最终门禁与窄窗口目视结果记录在本地交接，不以本 ADR 代替实际测试。
