# ADR-0030：批量关闭标签与保存选择

- 状态：Accepted
- 日期：2026-09-22
- 依据：用户要求快速关闭全部、所选标签左侧或右侧，并可逐个保存修改或全部保存。
- 修订：扩展 ADR-0009 的关闭入口和未保存提示；保留本地正文、共享 session、原子保存与外部冲突保护。

## 决策

1. 标签右键增加“关闭全部标签页”“关闭左侧标签页”“关闭右侧标签页”。全部作用于当前窗口所有编辑组；左右只处理右键目标所在组，不包含目标标签，没有相应标签时禁用。阅读模式同样可用。
2. 关闭前收集目标标签及其历史引用中的 dirty session，按文档去重；仍由保留标签引用的文档不需保存或放弃。窗口退出沿用同一保存选择。
3. 未保存提示提供取消、放弃全部、逐个处理、全部保存并关闭。逐个处理显示当前完整路径，可保存当前文件或选择不保存后继续。先完成所有必要选择和保存，再统一关闭目标标签。
4. “不保存此文件”只记录本轮对当前正文的放弃选择，不立即删除 session。随后取消时保留全部标签和未保存正文；已经成功保存的文件保持保存结果。若该文档又发生修改，原放弃选择失效，需要重新处理。
5. 保存复用现有串行队列、Save As 身份迁移、外部版本校验及原子写盘。失败、取消另存为、外部冲突或保存期间再次编辑时停止关闭并保留整批标签；重试只处理尚未解决的文档。保存进行中禁止重复提交或放弃关闭。
6. 不增加持久草稿、跨文件原子事务或新 IPC。正常完成关闭后仍使用既有引用回收和窗口导航清理规则。

## 验证

- 左右范围、分屏全部关闭、空范围、菜单键盘导航与阅读模式入口。
- dirty 历史和共享文档去重；取消保留正文，逐个保存/不保存，全部保存。
- 中途保存失败、外部冲突、另存为取消/路径迁移、保存期间再编辑，以及窗口退出保存。
