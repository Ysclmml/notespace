# ADR-0010：工作区右键入口与单层目录创建

- 状态：Accepted
- 日期：2026-09-02
- 修订：ADR-0008/ADR-0009 中目录创建后置的范围及根工具栏呈现
- 保持不变：既有文件、保存、废纸篓、Tab/history 和单一右侧预览边界

## 背景

用户要求移除根下常驻的新建/定位按钮，把工作区当作根目录，参考 Typora 在根、子目录、文件和侧栏空白区域提供常用右键动作。删除确认框还会被长路径撑破，菜单字体和尺寸不一致。

## 决策

1. 移除每根常驻工具栏。根和局部空白的动作属于该根；整个侧栏余下空白属于活动根。文件上的新建属于其父目录，目录上的新建属于该目录。
2. 新增“新建文件夹”。命令 `create_workspace_folder(workspaceRoot, directoryPath, folderName)` 只在根内已存在父目录下创建一个空目录，使用 `create_dir`，不递归、不覆盖。规范化根/父目录并拒绝根外父目录、空名、`.`/`..` 和包含路径分隔符的名称。
3. 其余菜单复用现有语义：打开、在新主 Tab 打开、新建文件、按文件名查找、展开/折叠、复制路径、系统文件管理器定位、确认后移到废纸篓、关闭工作区。根永不提供删除磁盘内容动作。菜单不展示尚未实现的重命名、副本、全文搜索或新窗口。
4. 菜单采用独立紧凑字号、分组分隔、轻量圆角/阴影、鼠标悬停与键盘导航状态；弹层挂在侧栏裁剪之外并根据实际尺寸避开窗口边界。右键不先打开文件或选择文件名文本。
5. 删除和未保存确认框使用可收缩单列布局。长路径独立换行，正文过长时滚动，按钮始终在可见操作区内；Esc 取消，Tab 焦点留在对话框内。删除语义和 dirty 保护保持不变。
6. 所有新增标签、成功/失败提示提供中英文；Tauri 只增加上述一个实际命令，总数为 13。

## 最低验证

- 根/目录/文件同级和外部空白的新建位置正确；多根不会误用其他根，移除常驻工具栏后仍可操作。
- 创建目录支持 Unicode、根和子目录；同名文件/目录、非法名称与根外父目录拒绝，不改变已有内容。
- 文件右键可打开新 Tab，原 Tab 保持；根/文件的复制、定位、关闭/废纸篓继续按能力提供。
- 中英文菜单可键盘操作、Esc/外部点击/滚动关闭，不被侧栏裁切。
- 长路径、长文件名和窄窗口下确认框内容与按钮不溢出；取消不调用废纸篓命令。

## 明确不做

不新增重命名、移动、复制文件内容、永久删除、任意多窗口/分屏、通用文件系统接口或全文索引服务。
