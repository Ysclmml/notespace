# ADR-0013：浏览恢复与统一编辑分屏

- 状态：Accepted
- 日期：2026-09-03
- 依据：用户明确要求恢复浏览设置、将右侧代码预览合并到分屏、向右分屏移动原标签、当前页查找及隐藏文件开关。
- 修订：ADR-0007/0011 的独立只读右侧栏、分屏复制标签和不恢复浏览元数据的边界；ADR-0012 的窗口轨迹仍不持久化。

## 决策

1. 启动偏好为 `restore`（默认）或 `empty`。恢复只记录已保存文件路径、当前标签顺序/固定状态、扁平分组、活动页和数值阅读位置。正文重新从磁盘预检读取；不存未命名正文、选择文本、Undo、back/forward 或窗口导航轨迹。失效文件跳过，损坏便利状态可丢弃，启动期间的用户操作不得被迟到恢复覆盖。空白模式跳过工作区和标签自动打开，保留最近项供手动选择。
2. “在右侧打开”复用现有右邻编辑组；仅一个组时创建右组，不再额外添加独立辅助栏。代码进入普通 CodeMirror 预览标签，双击/编辑固定，dirty 内容与保存/关闭遵循普通标签规则。已有右组时新代码链接直接进入该组，干净临时标签可替换，固定或 dirty 页保留。若来源已经是最右组则复用该组且保留来源 Markdown。局部悬浮预览仍只读、有限行数。
3. 标签“向右分屏”移动同一 Tab 到右邻组（不存在则创建），不复制 Tab/session/history。移动唯一标签时可留下空白左组，便于继续打开文件；复用既有右组避免无意增加第三栏。拖动、分隔线、各标签阅读位置和 dirty 保护保持。
4. `⌘F` / `Ctrl+F` 查找当前活动页面，可视正文、Markdown 源码和普通代码均支持文本匹配、前后匹配和退出。查找是本地投影，不修改正文、不进 Undo，不扩展工作区全文索引。
5. 工作区根右键提供是否显示隐藏文件/目录的勾选项。每根独立持久偏好、默认关闭，递归用于该根子树；仍排除版本控制元数据、依赖/构建缓存与符号链接，不改变实际打开文件和磁盘权限。
6. 根使用明确工作区标识/层级间距并保留可访问折叠。代码块在转入外部正文输入后不再显示旧活动选区；链接编辑允许完整换行查看/编辑地址。所有新菜单、设置和查找文案均中英文。

## 验证与边界

- 恢复元数据白名单/边界、fresh disk、缺失路径、共享正文和独立视图、空白启动、取消关闭/确认关闭、迟到恢复不覆盖新页。
- 移动原标签保持身份与位置、唯一标签留空组、右侧代码复用两组、dirty 预览固定、快速点击 latest-wins。
- 可视/源码/代码查找、中文/无匹配/循环/Esc、不改正文；失焦选区、长链接字段；隐藏偏好递归/多根隔离与 Rust 枚举。
- 不增加正文快照、崩溃恢复引擎、递归分屏、网络上传、文件修改/权限扩张或通用框架。准确验证与产物由 PROJECT_STATE 记录。
