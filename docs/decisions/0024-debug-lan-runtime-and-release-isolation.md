# ADR-0024：Debug 局域网共享的运行时语义与 Release 隔离

- 状态：Accepted
- 日期：2026-09-04
- 修订范围：补充并纠正 ADR-0023 的运行时计数、地址发现、并发、停止和构建隔离语义；ADR-0023 的 Debug 无认证、用户显式启停、所选根、只读和 opaque ID 边界继续有效。

## 背景

ADR-0023 确立了可供多个手机同时读取的 Debug 无认证纵向链路，但“当前活跃客户端数量”会让人误以为桌面维护了设备会话或在线列表。当前 HTTP 协议没有配对身份、长连接或设备心跳，服务只能准确观察此刻尚未完成的请求，不能据此判断有多少手机在线。

局域网电脑也可能同时具有 Wi-Fi、有线、虚拟网卡等多个地址。mDNS 发现如果过早固定一个地址，会在首个候选不可达时把仍可连接的电脑误判为离线。与此同时，目录、正文、资源和全文搜索包含磁盘 I/O；若请求处理期间一直持有全局服务锁，多手机虽然能建立连接，实际读取仍会被串行化。

仅在启动函数中做运行时 Release 拒绝也不足以证明无认证链路不会被误带入发布包。桌面命令注册、移动真实 HTTP transport、CSP 明文来源和 Android 多播能力都必须在构建边界一起关闭。

## 决策

### 协议与桌面状态

- 协议状态、Rust/Tauri 状态和桌面面板统一把 `clientCount` 更名为 `activeRequestCount`，不保留同义兼容字段。
- `activeRequestCount` 只统计已经进入 HTTP 处理、尚未完成且未取消的瞬时请求。响应结束、连接失败或取消后立即减少；空闲手机不计数，同一手机的并行请求可计为多条。
- 该数字不是已配对设备数、在线手机数、已发现电脑数或 TCP 连接总数。值为 `0` 也不表示没有手机仍停留在阅读页；当前无认证协议不建立设备清单、在线状态或逐设备会话。
- 多手机能力以“多个独立请求可同时推进且互不取消”验收，不以计数值推断设备身份。

### mDNS 地址候选

- 一个 mDNS 服务实例返回去重后的多个可用局域网地址候选，而不是只挑选首个地址。候选只包含当前协议接受的非回环局域网地址，并与服务实例 ID、端口和协议版本一起返回。
- Android 按稳定顺序对候选基址逐一执行有界 `/api/v1/status` 探测；某个地址超时或拒绝连接时继续尝试下一个，首个返回兼容 `protocolVersion` 和实例信息的地址成为本次连接基址。
- 全部候选失败时才把该次自动连接视为失败；`host:port` 手动入口继续保留。重新发现可以更新候选，不能把一次成功地址永久当作电脑身份。

### 并发与锁边界

- 服务生命周期、共享根注册表和 opaque ID 映射可以短暂持锁，以取得本次请求需要的不可变快照或完成原子替换；目录枚举、文件打开/读取、资源传输、搜索扫描和响应写入不得持有全局服务锁。
- 每个 HTTP 请求独立使用其快照和预算。监听器可把多个请求交给独立执行单元，同一手机的并行加载和多个手机的目录、正文、资源或搜索请求不得因为全局互斥锁而串行。
- `activeRequestCount` 使用独立的并发安全计数，不为显示状态反向扩大服务锁范围。

### 停止、取消与旧 ID

- 停止共享先原子地把当前运行实例标记为已停止并触发取消，再关闭 listener、撤销 mDNS 发布和释放共享注册表。listener 关闭后不再接受新连接；旧实例的 workspace/document/asset ID 立即失效。
- 已接收但尚未完成的目录、资源或搜索任务在有界读取/枚举批次之间检查取消信号，命中后尽快终止且不返回部分内容。长任务必须可协作取消，停止操作不能等待完整搜索或大资源读取自然结束。
- 重启总是创建新的运行期实例和新的 opaque ID。旧连接即使晚到也不能访问新实例，停止前取得的快照不能在停止后继续作为有效授权。

### Release 构建隔离

- 无认证桌面 HTTP host、启动/状态/停止命令和 mDNS 发布只在 Debug 编译并注册；Release 不注册这些命令，也不能靠直接 invoke 启动服务。
- Android 的 mDNS 浏览命令和真实无认证 HTTP transport 只在 Debug 编译/选择。Release 不保留可通过隐藏 UI 或手动地址重新启用的分支。
- Release CSP 不为该链路开放局域网明文 `connect-src`；Android Release 保持明文流量关闭，不声明无认证发现所需的多播权限，也不获取 multicast lock。其他已经单独决策的联网能力不能被用作局域网通配放行。
- 自动验证分别检查 Debug 和 Release 的命令注册、前端构建常量、CSP、Android 合并清单与权限。运行时拒绝可作为额外保护，但不能替代编译和注册隔离。

## 验证

- 协议、adapter 和桌面 UI 测试只接受 `activeRequestCount`，并覆盖同一手机并行请求计为多条、响应结束归零以及不能把该值展示成在线设备数。
- mDNS 测试提供首个地址不可达、后续地址成功和全部候选失败三种情况；手动 `host:port` 仍可独立连接。
- Rust 并发测试让慢搜索与目录/正文请求重叠推进，证明磁盘 I/O 不持全局锁；停止测试覆盖 listener 拒绝新连接、在途长任务取消和重启后旧 ID 拒绝。
- Debug 构建核对真实链路、明文 CSP 和 Android 多播能力按需存在；Release 构建核对命令不可 invoke、局域网 HTTP transport 不可选择、CSP 无明文局域网来源且 Android 清单无多播权限/明文流量。

## 结果

桌面现在只展示它能可靠测量的“活跃请求数”，不会伪造无认证协议并不存在的设备在线状态。多地址探测和无全局 I/O 锁让真实局域网环境中的多手机读取更稳；停止与取消语义保证本次授权及时结束。更严格的 Release 构建隔离则防止开发期无认证链路因隐藏入口或宽泛权限被误带入正式包。
