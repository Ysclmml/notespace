# ADR-0011：编辑分屏、临时标签与图片链接预览

- 状态：Accepted
- 日期：2026-09-02
- 修订：ADR-0007/ADR-0010 的单主编辑画布限制，以及非编辑区保留默认浏览器右键的交互
- 保持不变：本地文本唯一真相、共享 DocumentSession、独立 Tab/history、一个只读辅助栏与三项实用护栏

## 背景

用户明确要求顶部标签右键分屏、标签跨分屏拖动、文件树单击临时预览与双击固定，以及新文件跟随光标所在分屏。活动文件应自动在树中显示，悬停和选中需清楚区分；WebView 的 Reload/Inspect 菜单只应在顶部工具栏可用。图片链接也需要独立的图片查看器，而非要求文件带行号或作为代码显示。

## 决策

1. 主编辑区使用扁平的横向 `EditorGroup[]`。默认只有一个左侧活动组，每组有自己的标签集合和活动标签；顶部工具栏、保存、历史和大纲跟随当前聚焦组。保留既有独立只读右侧辅助栏，不引入递归 pane tree、纵向网格或 IDE docking。
2. 标签右键“向右分屏”在该组右侧创建一组，复制该 Tab 的独立历史/视图并共享文档 session。可继续增加横向组；相邻分隔线可拖动或键盘调整，双击复位。每组保持可用最小宽度，窄窗口可局部横向滚动。
3. 标签可拖动到其他组的标签栏或编辑区域，也可通过菜单移动。移动同一个 Tab，不重建其文档 session、历史或当前编辑器；空组自动收起，最后一组为空时显示欢迎页。只接受应用自身标签拖放，不将外部文件拖放解释为移动标签。
4. 文件树单击在目标组打开至多一个临时标签，文件名用斜体；下次单击可替换该组的干净临时标签。双击文件或标签、“保持打开”、正文编辑、分屏或拖动都会固定。固定后保留普通字体，之后的文件树单击开启新的临时标签，不替换固定或 dirty 正文。各组临时标签互相独立。
5. 文件读取开始时捕获目标组/源 Tab。迟到结果不能跨组覆盖、复活已关闭源 Tab，或抢回用户后来切换的分屏焦点。快速连续文件树点击以该组最后一次请求为准；同组已有同路径 Tab 时优先激活它。
6. 同一路径在所有组仍只有一个 `DocumentSession`。可视/源码/代码表面的被动正文同步使用最小差异，不回传成新编辑、不抢焦点/滚动、不加入该表面的本地 Undo；位置按 Tab 独立。IME 期间暂存外部更新，结束后合并不相交改动；重叠以当前输入草稿优先，不建设协同/CRDT。
7. dirty 提示覆盖所有 Tab 的 current/back/forward。只有关闭最后一个相关引用时才询问是否放弃；确认后不得留下可复活已放弃正文的孤立 dirty session。保存完成后立即更新最新状态，关闭检测不能依赖过期监听器或旧渲染快照。
8. 激活工作区内文档时，以最长匹配根为归属，展开到目标并仅滚动侧栏使文件可见；不移动正文光标。相同路径输入、刷新或手动折叠不重复抢回展开状态。选中、悬停和键盘焦点使用清晰但克制的独立色阶。
9. 页面默认阻止 WebView 右键，不阻断应用自定义菜单事件。仅显式标记的顶部工具栏允许平台菜单；菜单/对话框及确认期间不放行。debug 原生“视图 → 开发者工具”由 Rust 直接打开调试器；release 不显示该项，不新增 invoke 或前端应用 action。
10. 常见图片链接点击后进入专门查看器，支持缩放、平移、Fit、100% 和 Esc 返回，保留原 Tab/分屏/dirty。支持本地相对/绝对路径、`file://` 及带扩展名的 HTTP(S) 图片链接；远程图片仅在用户点击时由 `<img>` 加载，不后台探测或上传文档。SVG 作为图片资源显示，不把文件原文插入 HTML。失败显示可关闭的本地化提示。代码/文本引用的行号仍是可选项。

## 最低验证

- 临时替换、双击/编辑固定、同组去重、各组独立以及默认左组。
- 两组/多组分屏、跨组拖动和菜单移动；移动保留 EditorView、历史和位置，空组回收。
- 聚焦目标与异步读取；源 Tab 移组/关闭后的迟到结果不得覆盖或重新打开。
- 共享 Markdown/代码正文、IME、被动更新不进 Undo、不改变另一组焦点/滚动；保存/Save As 与最后 dirty 引用关闭。
- 自动展开活动文件、嵌套工作区 owner、目录折叠保持、深色选中/悬停。
- 自定义菜单保留、顶部默认菜单例外、确认期阻止、原生 debug 项及中英文。
- 图片路径解析、无行号图片链接、失败/关闭/返回；普通 Markdown 与代码链接路由不退化。

## 明确不做

不增加多窗口、纵向/递归布局、窗口快照、编辑器服务、图片编辑或格式转换、远程内容预抓取、CRDT、账户、遥测或文档上传。
