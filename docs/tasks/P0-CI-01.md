## Goal and non-goals

目标：在权限最小、工具链和外部 Action 均可审计的 CI 中，从干净 checkout 执行文档门禁、格式、lint、类型、前后端测试、契约入口、安全/依赖扫描和 Tauri 调试产物构建；任一步失败即阻止合并，并上传可定位的 macOS 调试应用 artifact。

非目标：不实现或重解释 IPC 契约，不实现产品功能，不建立发布签名/公证，不把未来 nightly、E2E、故障注入或正式多平台发布冒充为本任务已交付。

## Changes made

- 新增 `Quality gate` workflow：PR、`main` push 和手动触发均在固定 `macos-15` runner 执行，60 分钟硬超时、同 ref 新运行会取消旧运行。
- workflow token 只有 `contents: read`；checkout、setup-node、upload-artifact 均固定完整 commit SHA，checkout 不持久化凭证。
- 从仓库文件固定 Node 24.14.0、pnpm 10.32.1、Rust 1.98.0，并用 frozen lockfile 安装；记录实际版本便于失败定位。
- 串联 repository hygiene、设计文档、npm/RustSec 审计和权威 `pnpm verify`，随后构建 `.app`、保留权限地压缩并上传 7 天 artifact。
- 新增无依赖 Ruby hygiene gate 及自测，拒绝个人绝对路径、私钥、大 Base64、超大 tracked 文件/单行、危险文件名、`pull_request_target` 和未固定 SHA 的 Action。

## Decisions and assumptions

- CI primary runner 与 macOS 首发方向一致；正式全平台矩阵和签名/公证仍属于后续阶段。
- GitHub Actions 必须固定到完整 commit SHA，并用注释记录对应 release tag；workflow token 仅授予 `contents: read`。
- Node 从 `.node-version` 读取，pnpm 使用 `package.json` 的精确版本，Rust 由 `rust-toolchain.toml` 固定；不得使用漂移的 `latest` 工具版本。
- 本任务只接线统一 `pnpm verify`；契约 owner 应把 schema drift/contract gate 纳入该入口，CI 不复制第二套语义。
